★★ 看護学校 面接練習ページ（准看護・正看護・看護系大学）★★  江原予備校

【これは何か】
公務員版（面接練習）とは別に作った、看護学校・看護系大学の面接練習ページです。
・区分：准看護／正看護／看護系大学（問題集が区分ごとに切り替わります）
・受験校（熊本県の正看護・准看護17校は一覧から選べます。大学などは学校名を入力）、
  試験形態（個人面接・集団面接・集団討論・小論文・作文・学科・口頭試問）、面接日・面接時間を最大5校まで登録できます。
・面接日までの日数を表示。学校の理念・キーワード・公開資料にある試験情報を表示。
・集団面接・集団討論が含まれる受験校では、「集団面接・集団討論」の問題が最初から選ばれます。
・問題数：准看護48／正看護49／看護系大学51（共通の質問＋区分ごとの質問＋集団面接・討論＋休学・通信制・ブランク・社会人の方向け）。
・点数は、端末の中で計算する「目安点」と、設定すればClaudeによる「AI採点」の2種類（公務員版と同じしくみ）。

【生徒さんへの注意】
・模範例の〔 〕（黄色）は、自分の事実で埋める部分です。事実と違うことは話さない。
・学校の情報（schools.js）は公開資料（2026年10月14日調査）のものです。出願前に必ず最新の募集要項で確認してください。
・志望校・面接日などの入力と練習記録は、この端末のブラウザの中だけに保存されます。

【ファイル】
 index.html    本体        questions.js  問題データ（区分ごと）
 schools.js    県内看護学校の情報      config.js  合言葉・AI採点の設定
 make_audio.py 読み上げ音声（任意）    Code.gs    AI採点と成績記録（任意）

【1. 合言葉を変える】
初期の合言葉は「kango2026」です。必ず変更してください。
index.html#setup を開き、新しい合言葉を入力 → 表示された passHash の行を config.js に貼り付けます。

【2. 公開する】
GitHubのページ等に新しいリポジトリ（例：kango-mensetsu-renshu）を作り、上のファイルを置いて公開します。
公務員版（mensetsu-renshu-otsu）のフォルダには置かないでください。

【3. 読み上げ音声（任意）】
VOICEVOXを起動して python make_audio.py を実行し、できた audio フォルダを index.html と同じ場所に置きます。
音声がない間は、ブラウザ内蔵の声で読み上げます。VOICEVOXの利用規約・クレジット表記をご確認ください。

【4. AI採点と記録（任意・公務員版とは別に作る）】
公務員版の endpoint と appToken は、ここでは使いません（記録が混ざるため）。
① 新しいGoogleスプレッドシートを作る（例：看護面接練習の記録）
② 拡張機能→Apps Script に Code.gs を貼り付けて保存
③ スクリプトプロパティに APP_TOKEN（長い好きな文字列）、ANTHROPIC_API_KEY、必要なら MODEL・DAILY_LIMIT を登録
④ デプロイ→ウェブアプリ（実行：自分／アクセス：全員）→発行されたURLを config.js の endpoint へ、APP_TOKEN と同じ文字列を appToken へ
⑤ 生徒さん（未成年は保護者）に、お名前・回答の文字・点数をGoogleと採点AIに送ることを説明し、同意を得てから使う
※ endpoint と appToken は config.js に書かれ、ページを開ける人には見えます。DAILY_LIMIT で上限をかけてください。
